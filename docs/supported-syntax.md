# Supported syntax — v0.1.0

Supported at the declared-configuration level: `name`, `on`, workflow/job `permissions`, workflow/job `concurrency`, jobs, job `name`, `needs`, `if`, `runs-on`, `strategy.matrix`, `environment`, `timeout-minutes`, job-level reusable `uses`, steps, step `uses`, step `run`, and step `with`. Literal artifact names from `actions/upload-artifact` and `actions/download-artifact` are linked.
